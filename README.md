# Fader — Per-Tab Volume Mixer

Control the volume of every browser tab independently. Boost, mute, and mix audio across all your tabs — settings saved automatically per website.

## Features

- Per-tab volume control (0–200%)
- Master volume slider
- Mute/unmute per tab without losing slider position
- Mute all tabs instantly
- Volume settings saved per domain (survive page reloads)
- Auto-restores volume after tab refresh
- Pin Fader as a persistent tab for quick access
- DRM detection (Netflix, Disney+)
- Keyboard shortcut: `Alt+Shift+F`

## Installation

1. Download or clone this repository
2. Go to `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the `fader/` folder
